# Hadjas 2025 conversion

Documentation of the conversion of the recordings of Hadjas et al. (2025) to NWB, for lab members who run it. For the
conversion pipeline in general, see the [repository docs](../../../../docs/).

1. [Data organization](data_organization.md): the data share layout, cohorts, protocols and lab files.
2. [Converting sessions](converting_sessions.md): checking the data, converting sessions, and the output files.
3. [Data streams](data_streams.md): raw and processed signals, raw-only conversion, recomputed signals.
4. [Behavioral video](behavioral_video.md): preparing the AnyMaze videos and switching on their conversion.
5. [Metadata](metadata.md): editing the metadata files, adding a cohort, ontology terms.
6. [NWB file structure](nwb_file_structure.md): what is stored where, and how to read a file.
7. [Processing](processing.md): the Python port of the lab's processing and how it compares with the lab's.
8. [DANDI staging](dandi_staging.md): organizing, validating and uploading the files.
9. [Troubleshooting](troubleshooting.md): data check findings and conversion errors.
